ORGANIZADOR IA V1.2 — WEB
- Analiza TXT/CSV/MD/JSON/XML/HTML localmente.
- Extrae texto de PDF (hasta 30 páginas por archivo).
- Extrae texto de DOCX.
- OCR de imágenes en español mediante Tesseract.js.
- Genera categoría, nombre y destino propuestos.
- Permite revisar y seleccionar propuestas.
- Exporta un informe.
- NO mueve, renombra ni elimina archivos.

NOTA: PDF/DOCX/OCR cargan librerías desde Internet (CDN). Para usar esta versión basta con abrirla mediante un servidor HTTPS; algunas funciones pueden no funcionar con file:// por las restricciones del navegador.
